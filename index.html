Vestaboard mit Gesichtserkennung

 
6

Mein Abschlussprojekt im Rahmen meiner Umschulung zur Fachinformatikerin für Anwendungsentwicklung: Ein physisches Vestaboard — ein Split-Flap-Display wie am alten Flughafen — erkennt per Gesichtserkennung, wer davorsteht, und zeigt automatisch dessen offene Jira-Tickets und nächste Outlook-Termine an.

  • face_recognition() → KI-Kamera erkennt Mitarbeitende automatisch
  • jiraTickets → offene Tickets mit Priorität, live über die REST API
  • outlookEvents → nächste Termine über die Microsoft Graph API
  • hybridCloud → Docker lokal, DSGVO-konform, 24/7 via systemd
